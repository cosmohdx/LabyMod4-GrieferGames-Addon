# LabyMod 4 GrieferGames Addon

Erweitert LabyMod um viele nützliche Funktionen für den [grieferGames.net](https://griefergames.net) Server.

Feature-Übersicht: [FEATURE.md](FEATURE.md)

### Installation

Download im Spiel über den LabyMod Store oder manuell als Release-JAR.

Ordner für manuellen Download:

| Betriebssystem | Ordner |
|---|---|
| Windows | `%APPDATA%\.minecraft\labymod-neo\addons` |
| Linux | `~/.minecraft/labymod-neo/addons` |
| macOS | `~/Library/Application Support/minecraft/labymod-neo/addons` |

Repository: [cosmohdx/LabyMod4-GrieferGames-Addon](https://github.com/cosmohdx/LabyMod4-GrieferGames-Addon)
